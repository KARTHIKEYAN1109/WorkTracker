# WorkTracker

A full-stack web application for tracking and managing work activities, built using React, Node.js, Express.js, and MongoDB.

## Features

* User Authentication
* Work Entry Management
* Create, Update and Delete Work Logs
* Effort Tracking Dashboard
* Responsive User Interface
* Secure API Integration

## Tech Stack

### Frontend

* React.js
* Vite
* Axios
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication

## Installation

Backend

```bash
npm install
npm start
```

Frontend

```bash
cd frontend
npm install
npm run dev
```
